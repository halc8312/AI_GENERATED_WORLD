# 創世界 (Sousekai) — AIが紡ぐ世界

> はじめに、**無**があった。無は完全であり、完全であるがゆえに不安定であった。そして、無は揺らいだ。その揺らぎが——*すべて*のはじまりだった。

## 概要

「創世界」は、AIが構想した完全な世界をインタラクティブなWebブラウザ体験として構築したプロジェクトです。宇宙の誕生（ビッグバン）から文明の興亡、そして世界の終焉と再生まで、あらゆる事象をプロシージャル生成によってシミュレートします。

🌐 **[GitHub Pages で体験する](https://halc8312.github.io/AI_GENERATED_WORLD/)**

## 世界の構造

この世界は8つの章で構成されています：

### 第一章：創世 — はじまりの刹那
- ビッグバンのシミュレーション
- 宇宙膨張の可視化
- エネルギー密度と温度の推移

### 第二章：宇宙 — 無限の深淵
- 渦巻き銀河の生成
- 恒星の種類（赤色矮星、青色巨星、中性子星など）
- 超新星爆発とブラックホール形成
- 恒星カタログの自動生成

### 第三章：大地 — 揺れ動く大地
- パーリンノイズによる地形生成
- プレートテクトニクスシミュレーション
- 火山噴火と地震イベント
- 地質年代の切り替え（冥王代〜新生代）

### 第四章：海洋 — 生命の揺りかご
- 波のシミュレーション
- 海流の可視化
- 深海の生物発光
- 海洋統計データ

### 第五章：大気 — 天空の織物
- リアルタイム天気シミュレーション
- 雨、雪、雷雨、霧、オーロラ、虹
- 季節変動システム
- 気象データダッシュボード

### 第六章：生命 — 奇跡の連鎖
- 進化シミュレーション（食物連鎖）
- 複数種の生態系
- 自律行動AI（捕食、逃避、繁殖）
- 進化タイムライン

### 第七章：文明 — 知恵と創造
- 都市の建設と発展
- 文化圏の生成と交流
- 発明の歴史（火の制御〜ワープ航法）
- 歴史イベントの自動生成（戦争、和平、探検など）
- 文明マップの可視化

### 終章：時間 — 永遠と刹那
- 宇宙のライフサイクル（膨張→平衡→熱的死→再生）
- エントロピーの可視化
- 哲学的思索カード
- 世界の再創造

## 技術構成

- **HTML5 Canvas** — すべての描画はCanvas APIで実装
- **バニラJavaScript** — フレームワーク不使用、ビルドステップ不要
- **CSS3** — アニメーション、グラデーション、レスポンシブデザイン
- **プロシージャル生成** — パーリンノイズ、シード付き乱数生成器
- **GitHub Pages** — 静的サイトとしてデプロイ

## ローカルでの実行

ビルドステップは不要です。任意のHTTPサーバーで `docs` ディレクトリを配信してください：

```bash
# Python 3
cd docs && python -m http.server 8000

# Node.js (npx)
npx serve docs

# あるいはブラウザで直接開く
open docs/index.html
```

## 設計思想

この世界は以下の原則に基づいて設計されています：

1. **自律性** — 各モジュールは独立して動作し、世界は人間の介入なしに進行する
2. **創発性** — 単純なルールの組み合わせから複雑な現象が生まれる
3. **物語性** — 科学的シミュレーションに詩的なナラティブを重ねる
4. **観測者の存在** — 観測者（あなた）がいてこそ、この世界は意味を持つ
